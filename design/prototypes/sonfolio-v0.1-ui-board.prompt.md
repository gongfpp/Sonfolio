# Sonfolio V0.1 前端原型提示词

生成一张面向 Android 的高保真中文 App 原型板，横向并列展示四个完整手机界面，视觉应接近可落地产品，不使用概念艺术风格。

1. 「今天」首页：显示“今天 · 9月8日”“已连续记录 6小时 42分”，录音状态卡包含“正在记录”“下一段将在 18 分钟后保存”和唯一操作“★ 标记刚才”。下方按时间轴展示四场对话：“09:32 与同事讨论系统投产 · 12分钟”“12:11 午饭多人聊天 · 28分钟”“14:40 记录一个游戏想法 · 3分钟”“18:20 与未知人物对话 · 7分钟”。底部导航为“今天、搜索、设置”。
2. 对话详情：标题“与同事讨论系统投产”，显示“09:32–09:44 · 12分钟”、原音播放波形、播放进度“02:18 / 12:06”、09:38 的星标位置、“本地转写”标签以及带时间戳的三段中性转写，不出现人物身份判断。
3. 全文搜索：标题“搜索记忆”，搜索词“电梯 断电”，筛选项“全部、今天、本周、仅标记”，显示“找到 2 条相关内容”，关键词在结果内高亮。
4. 录音与存储：标题“录音与存储”，显示录音服务正常、已使用 18.6 GB、预计还可记录 47 天，以及“完整录音 30天”“有效人声音频 永久保留”“标记片段 永久保留”。“仅在充电时执行语音识别”关闭，“原始音频永不上传”开启，底部注明“所有核心处理默认在本机完成”。

整体使用暖白背景、炭黑文字、森林绿录音状态色和少量琥珀色星标，参考克制的 Material 3 设计，中文无衬线字体清晰，留白紧凑但舒适。四台手机正面等大、完整显示、窄边框。不要使用渐变、玻璃拟态、未来全息风、装饰插画、类别繁多的标记按钮、说话人库、Todo、AI 日记、原始文件名或水印。
