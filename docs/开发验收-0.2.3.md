## 过程中发现并修复的缺陷

- **`ModelDownloadControl` 组合期哈希大模型**：SenseVoice 239 MB / Qwen3 987 MB 的 SHA-256 在 UI 线程执行，进入设置或切换引擎都会卡住。新增只比大小的 `ModelCatalog.available` 并放到 IO 线程；磁盘可用空间与播放时间线构建同样移出主线程。搜索输入改为 220 ms 防抖，转写行高亮按行缓存。
- **`WavPcmReader` 只认固定 44 字节头**：ffmpeg/afconvert 会在 `fmt` 与 `data` 之间插入 `LIST`/`FLLR` chunk，导致评测音频被读成 13 个采样，一度误判为「Qwen3 全部空转写」。改为顺序扫描 `fmt`/`data`，并为流式 WAV 做长度兜底；新增 JVM 测试覆盖两种布局，`AudioTranscoder` 同步改为按真实 data 布局读取。
- **误判更正**：Qwen3-ASR 真机可用，之前结论由坏素材导致，相关文档与设置页警示已更正。
