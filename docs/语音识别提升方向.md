# 语音识别提升方向（调研与计划）

日期：2026-09-17。目标：回答「微信输入法/豆包/元宝为什么更准、本地模型是不是到顶了、我们能怎么提升」。

## 他们是怎么做的

- **输入法/助手类产品的识别主体在云端，不在端侧。** 腾讯云 ASR（被微信、王者荣耀等使用）公开口径是中英混说 CER ~4%，并配有天籁实验室降噪前端（覆盖 300+ 噪声类型）；混元 ASR 是 LLM 流式模型，把语音编码器输出映射进 LLM 纠偏声学歧义，专有名词 CER 相对降 6.4%、粤语优化 >9.6%。
- **云 + 端混合是通行架构。** 端侧做 VAD/降噪与轻量兜底，云端做大模型识别并返回结构化结果；输入法还会把用户词库/热词、上下文、历史输入一起送去做重排。
- **ASR 之后普遍再接一层 LLM 纠错。** 典型管线是「ASR 原始文本 → LLM 按上下文纠错/加标点/术语标准化」，公开案例报告 WER 相对下降 15–30%（如腾讯云 ASR + DeepSeek 校验纠错方案）。
- 结论：**他们的优势来自云端大模型 + 降噪前端 + 大词表热词 + LLM 后处理，不是单靠某个端侧模型。**

## 本地模型是不是到顶了

不是「到顶」，而是**在手机 CPU 上有明确的算力/内存上限**：

| 模型 | 规模 | 中文公开基准 CER（越低越好） | 端侧可行性 |
| --- | --- | --- | --- |
| Whisper-Large-v3 | 1.6B | 平均 9.86%（中文偏弱） | 可跑但慢且中文一般 |
| SenseVoice-L | 1.6B | 平均 4.47% | 可行（本项目现用 int8） |
| Paraformer-Large | 0.2B | 平均 4.56% | 可行、快 |
| **Qwen3-ASR-0.6B** | 0.6B | 官方称最佳「精度-体积」折中，中英与方言领先 | 可行（本项目已接入） |
| **FireRedASR-AED** | 1.1B | 平均 **3.18%**，优于 Seed-ASR(12B+) | 偏大但可行 |
| FireRedASR-LLM | 8.3B | 3.05% | 手机不现实 |
| Qwen3-ASR-1.7B | 1.7B | 开源 SOTA、接近顶级商业 API | 手机偏重 |

即：**端侧还有可挖空间（FireRedASR-AED 明确比 SenseVoice 低约 1.3 个点 CER），但要把「元宝四六开」当成目标，必须走云端大模型 + LLM 纠错。**

## 我们的现状与提升路线

已在 `docs/evaluation/README.md` 记录真机实测：Qwen3-ASR-0.6B 在 Redmi Note 8 Pro 上粤语 CER 0.000、英文 0.069、中文绕口令 0.079、快语速 0.154、带噪对话 0.321。

按性价比排序的可做项：

1. **LLM 纠错后处理（已实现，4.1）**：对话详情新增「AI 纠错」，复用已配置的总结模型（本地 GGUF 或在线 API）分批纠正错别字与标点，原始转写保留在 `originalText`，可「撤销纠错」一键还原。模型返回句数不一致时对短批次逐句重试，仍失败则跳过并保留原文；检测到提示词/示例/JSON 结构泄漏时直接丢弃，避免写坏转写。
   - 真机实测（Redmi Note 8 Pro）：本地 0.5B 模型能力有限——会把提示中的示例复读回来、句数也常不一致；已加泄漏防护与逐句降级，**建议把「在线总结」配置为更强模型专门用于纠错**，或导入更大的本地 GGUF。
2. **再加一个更强的本地引擎（已接入并真机验收，4.2）**：新增 FireRedASR2-CTC int8（单模型 776 MB + tokens，`csukuangfj2/sherpa-onnx-fire-red-asr2-ctc-zh_en-int8-2026-02-25`，哈希已固定），与 SenseVoice/Qwen3 并列可选。CTC 非自回归解码，比 Qwen3 的 LLM 解码快。
   - 真机同素材对比（Redmi Note 8 Pro，2026-09-18）：FireRed 平均 CER **0.188**／105.8 s；Qwen3-ASR-0.6B 平均 0.270／158 s。
   - 分项：中文带噪 0.264（Qwen3 0.321）、**歌曲 0.228（Qwen3 为 `language` 缺陷）**；中文干净与英文 Qwen3 更好（英文 0.069 vs 0.282）。
   - 建议：中文为主选 FireRed，英文/中英混说选 Qwen3，默认仍用体积最小最快的 SenseVoice。
3. **前端质量**：接入降噪/去混响（如 sherpa 的 GTCRN/DPDFNet）再送 ASR；把 VAD 合并窗口调优（合并短段给模型更多上下文）。
4. **热词与个人词库**：已有「个人词汇」热词，继续从用户修正里积累；云端可加 `hotword_id`/大词表。
5. **云优先选项**：把「在线识别（Qwen3-ASR-flash）」明确标注为最高精度路径，本地作为离线兜底。
