## 本轮范围

- 录音采集不等待 Room 写事务；恢复日志和异常进程退出的数据保全。
- 受影响对话/日期的增量整理、计算移出写事务、合并后的旧 ID 重定向。
- 已排队任务的充电限制更新、明确处理阶段和终止原因、可操作的继续/重试入口。
- 原音列表分页、日期记录标记、切片上下文说明、可配置的回溯标记时长。
- 保留文本与标记的原音清理、真实导出结果、手动完整备份恢复方案。
- ASR/VAD 与 GGUF 模型按需下载、完整性校验、小 APK；原始音频默认不上传。
- 常用外部文本 API 提供商选择、官方模型列表获取、API Key 帮助。
- 本地总结同一任务内复用模型、长内容上下文与实际生成验收。
- README 使用截图、构建/测试/隐私检查与发布工程。

## 9 月 14 日真机反馈返工

- 首页黄星显示“标记（3分）”，附带两个分钟快捷按钮；主页卡片底部可点“每 5 分钟保存一份原音 · 切片说明”。说明明确文件边界不等于对话边界、跨片段合并和总结上下文限制。

- 外部文字总结使用提供商和模型下拉框，直接展示官方 API Key 页面链接。只有主动选择“自定义 · 高级”才手填地址。
