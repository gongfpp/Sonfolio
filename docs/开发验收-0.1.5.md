# 声迹 0.1.5 开发与验收记录

本轮于 2026-09-12 继续开发，在 0.1.4 已完成的录音与处理链路上补齐多日使用体验，版本为 `0.1.5 / versionCode 6`。改动覆盖日期浏览、当日录音统计、页面返回与状态保存、长列表布局，没有替换录音引擎、模型或音频格式，也没有新增后端、网络上传、自动清理或数据库迁移。Room Schema 保持版本 1，未操作手机现有录音；仓库中原有 `.workbuddy/` 和竞品调研文档保持不动。

后续状态补记：同日 `0.1.6` 已覆盖安装到原 Redmi Note 8 Pro，搜索/设置/原音路由和搜索状态在底栏切换、Activity 重建后的保留共 2 项真机通过；日期传递测试受自动锁屏影响，实际日期选择器与新版长转写回听仍待验收。下表保留 0.1.5 开发当时的证据，最新真机结果以 [0.1.6 验收记录](开发验收-0.1.6.md) 为准，不能把后续部分通过理解为日期相关交互已全部通过。

首页默认展示当前日期，可用前后一天按钮或日历选择历史日期；没有记录的日期明确显示空状态。一日回顾和原始录音入口继承首页所选日期，原音页可在当日与全部录音之间切换，设置中的入口仍展示全部录音。跨午夜的 Conversation 和原音在相交的日期都可找到，详情保留完整转写和回放范围，并显示跨日提示；一日回顾只使用与当日相交的转写，无法按午夜拆分的一句话会在两天均保留并注明“跨日内容”，不会把整场对话的所有内容复制给第二天。

已保存时长按数据库记录的 WAV 大小减去 44 字节头部，再依据采样率、声道数和 PCM 16-bit 换算，而不是依据录音按钮运行时间或恢复时的文件修改时间。统计先截取当日部分，再合并重叠区间，避免跨日或重叠文件重复计时；正在录音的零长度切片可见但不贡献时长，计数随后跟随每 5 秒检查点刷新。首页可展开当日已知中断的时间和原因，取消了缺口查询只取最近 20 条的限制；用户没有开启录音的时段不生成缺口，也不据此推断已经完成全天无遗漏记录。

页面导航现在保存实际打开来源：搜索进入对话后返回搜索，首页进入原音后返回首页，设置进入原音后返回设置。底栏切换保留搜索文字、筛选和列表位置，首页保留所选日期，保存的路由栈兼容旧版路由并对无效日期回退；日期或搜索条件变化时重新订阅结果，避免短暂显示上一条件的旧内容。时间线、原音、搜索结果和展开后的长转写均改为 `LazyColumn`，播放器继续固定在详情底部，搜索输入和筛选固定在结果上方；这属于按需布局，Room 目前仍返回完整列表，不宣称完成长期大数据量分页优化。
