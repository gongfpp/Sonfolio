# 2026-09-29 审阅落实与真机验收

本轮基于 `codex/review-reliability-redesign` 的 `8a31252` 继续。设计输入为用户提供的 `sonfolio-review.md`、`implementation-plan.md`、`sonfolio-redesign.html` 与两张设计板。用户明确：只参考布局、层级和交互，不照抄原型文案，首页继续叫「声迹」。

## 本轮代码改动

- 首页缩减常驻说明，统计按需展开；默认标记按钮持续显示分钟数，搜索/设置页录音时保留快捷标记入口。
- 设置首页只显示分类入口和已生效配置；录音设置、处理与整理、存储与备份、用量记录进入二级页。保留语言、词汇、过滤、模型下载/导入等已有能力。
- 对话详情分为小结/结构化转写，播放器固定底部；普通进入默认看小结，搜索命中进入对应转写；增大阅读字号和部分触控目标。
- 一日回顾增加当日对话入口供核对，并明确列表不等于每段生成文字的逐句来源。日期按钮现在能打开日历。
- 语义颜色支持系统浅/深色外观，系统栏提供夜间资源；保留直接、功能性的中文文案。
- 修复 `ChunkProcessing.stagedLabelOf` 对等待态 `active == null` 的强制解引用。该缺陷可导致原始录音列表闪退，但没有足够日志证明它是用户历史闪退的唯一原因。
- 标记使用共享 `MarkerSaveState`，按请求 ID 接收真实保存结果；无关录音错误不再结束正在保存的标记。已落库后的通知/重建异常不再发布保存失败。
- 清理数量跟随实际集合而非仅列表长度更新；候选查询排除时间窗口及整场对话的标记保护；提供可见的「选择录音」入口，默认仍不显示勾选框。
- 普通导出用按录音 ID 的共享读取保护，不再持有全库锁完成 ZIP；已明确清理音频的记录可导出文字，意外缺失仍明确报错。占用原因区分识别、导出等，不再都称作未处理。
- 完整备份升级到独立字段契约 v4，拒绝未知字段/类型错误，不再随 Room 的 `SELECT *`/`PRAGMA` 自动改变格式。
- Room 13 新增只读旧备注档案。旧库升级以及 format 1/2 恢复中的非空备注保留在独立表，不被后续对话重建覆盖；设置的完整备份区可查看和复制。已被历史版本删除的备注不能凭空恢复。
- 固定历史格式样例取自仓库 schema 5/9/10 的字段结构，属于重建的虚构测试数据，不宣称是旧 APK 实际导出的用户备份。恢复核对标题、备注、关联、标记与音频，再次导出恢复核对备注。
- 升级前/后脚本核对全部受管音频格式，不只检查 WAV；真机套件支持显式选择类，仍强制 QA 包隔离、TCP 真机、每类前后检查个人原音。
- 在线窗口重试不再凭相同模型名称复用缺少配置版本的旧转写；只使用当前配置版本与语言的窗口检查点。多轮失败时也保留先前成功窗口的文字。新增三窗口请求计数、配置变化和取消回归（使用可控请求回调，不宣称真实云端计费验收）。
- 真机横屏复现搜索页筛选区把结果提示挤出可视区，改为单行可横向滚动筛选，并在低高度窗口缩减标题/间距；保留防抖、分页、命中定位与页面恢复。存储页保留策略按钮改为自动换行，避免「自定义」被压成两行。

## 仍须明确区分的范围

- 完整备份/恢复仍有较长的全局文件锁；普通导出与识别已经拆分为读取保护，不代表全部 B06 并发目标完成。
- 现有队列更新保留纠错 Worker 类型，但尚需补充同时排入两种真实 Worker 的运行回归；可控窗口请求计数也不等于真实提供商联网与计费验收。
- 本轮没有真实付费提供商 API Key 验收，也未进行一整天耗电、后台稳定性与识别质量测评。
- 设置按阶段整理了入口，但尚未将全部等待原因统一成类型化状态页；日记还没有逐段可信引用映射。不能宣称十页原型全部等价落地。
- 不把这轮开发 APK 当作可公开发布 Release。正式发布仍需完成剩余门禁、签名核对和发布前审计。
