# 设置与日历体验优化

本轮对应用户提出的五项反馈，继续使用 `codex/review-reliability-redesign`。保留现有文案风格，不引入原型里的示例文案。

## 行为变化

1. 设置分类统一进入应用内二级页，不再混用全屏 Dialog。转文字、总结、标记时长、对话合并间隔的选项使用同一套可滚动单选弹窗。二级页隐藏底栏，避免切换 Tab 时丢失草稿；录音中仍保留快捷标记。未保存返回需确认。
2. 在线用量增加按功能、按模型分类。新记录区分转文字、转写纠错、对话总结、一日回顾、连接测试，并保存提供商和模型。旧记录保留，无法补分的字段明确说明，不推测历史用途。月度总量不重复累计详细记录。本地推理仍不计入在线用量。
3. 配置保存期间防止重复提交；成功后返回设置首页，更新已生效摘要并显示保存反馈，保留设置列表滚动位置。失败留在原页，已落盘但调度失败会明确区分。模型选择的处理速度、识别准确度分别显示为相对分值，不再用容易被误解为推荐标志的星星。
4. 两周日历的浏览窗口独立于选中日期，点击窗口内日期不会隐藏后续日期，也不再把页面滚回顶部。增加前两周、后两周、回到今天；日期触控区域加高。从月历选到窗口外日期时才定位新窗口。
5. 设置新增后台运行页面，展示系统电池优化、后台限制、省电模式和应用通知状态。提供官方电池优化、通知、应用信息入口，返回时刷新。厂商自启动、最近任务锁定无法可靠读取，明确提示用户确认；不自动修改系统设置，不承诺永久保活。

后台运行入口参考 Android 官方 [Doze 与 App Standby](https://developer.android.com/training/monitoring-device-state/doze-standby) 和 [后台限制](https://developer.android.com/topic/performance/background-optimization)。不请求特殊豁免权限，也不使用未公开的厂商 Activity。

## 统计口径与兼容

- 记录收到成功响应的本机在线调用，而非提供商账单。失败或超时请求也可能收费，不能用本机次数推算应付金额。
- 保留原有月度累计键，新增详细维度键；旧总量扣除新详细量后显示历史未区分部分。
- 不修改 Room 数据库版本或原始音频格式。
- 开发版本 `0.2.4-dev4（17）`，不是正式 Release。
